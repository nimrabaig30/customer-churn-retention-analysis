# Customer Churn & Retention Analysis 📊

## 📌 Project Overview

This project analyzes customer churn patterns using Power BI to understand customer behavior, identify potential retention opportunities, and support data-driven business decisions.

## 🎯 Objectives

* Analyze customer churn rate and customer retention.
* Explore churn patterns across contract types and customer demographics.
* Examine relationships between churn, internet services, payment methods, and additional services.
* Develop actionable recommendations to improve customer retention.

## 🛠️ Tools & Technologies

* **Power BI** — Data visualization and dashboard development
* **Power Query** — Data cleaning and transformation
* **DAX** — KPI calculations and measures
* **Microsoft Excel / CSV** — Dataset handling

## 📈 Key Performance Indicators

* **Total Customers:** 7,032
* **Churned Customers:** 1,869
* **Customer Churn Rate:** 26.6%
* **Average Monthly Charges:** 64.80

## 📊 Dashboard Pages

1. **Customer Churn & Retention Overview** — Key metrics and churn patterns.
2. **Customer Churn Analysis** — Churn by gender, senior citizen status, dependents, and partner status.
3. **Services Analysis** — Churn across contract types, internet services, payment methods, and tech support.
4. **Customer Insights** — Customer tenure, monthly charges, and additional services.
5. **Insights & Recommendations** — Proposed actions to improve retention.

## 💡 Recommendations

* Identify at-risk customers and develop targeted retention campaigns.
* Test incentives that encourage longer-term contracts.
* Improve onboarding and early customer engagement.
* Personalize service offers based on customer needs.
* Investigate payment-related churn patterns.
* Monitor customer feedback and resolve recurring issues.

*These recommendations should be validated against the dashboard findings before being treated as confirmed churn drivers.*
